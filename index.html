자비서 (JARVISEO)

안경에 카메라를 단 착용형 AI 비서. "자비서, 저거 뭐야?" 하고 부르면 본 장면을 판단해 음성으로 답합니다.

기간 2026.09 ~ 2026.11인원 3명담당 음성 · 기억 검색 · 배포

일반 안경테에 초소형 USB 카메라를 붙이고, 호출어부터 대답까지 한 번에 이어지는 파이프라인을 LangGraph 로 묶었습니다.

호출어 감지 → 프레임 캡처 → STT → 의도 라우팅 → 객체 검출 · OCR · 기억 검색 → 지시 대상 특정 → VLM 응답 → TTS

내가 한 일

  • 한국어 호출어 "자비서" 분류기 커스텀 학습 (openWakeWord 방식, Colab, 6회차 반복 실험, ONNX 배포)
  • 호출어 2단계 확인: 감지 직전 구간을 다시 받아써 TV · 대화 오탐 차단
  • STT · TTS 음성 루프, 끼어들기, 시작음 · 종료음, 응답 지연 최적화
  • 대화 기록 기반 기억 검색 ("아까 본 그거 뭐였지?") · PostgreSQL + pgvector
  • Docker · GitHub Actions CI · 배포

선행퀘스트 (Good Deed Quest)

작은 선행을 게임 퀘스트로. AI 가 맞춤 선행을 추천하고, 사진으로 인증하면 보상과 숏폼 영상이 남는 공익 플랫폼 앱.

기간 2026.06.26 ~ 2026.08.11인원 5명담당 AI 숏폼 생성 · 마이 페이지

인증 사진을 고르면 AI 가 자막과 배경음악을 입혀 세로 숏폼 영상을 만들어 줍니다. 이 생성 파이프라인 전체와 앱 화면 연동을 맡았습니다.

Vision Agent (Gemini, OpenAI 폴백) → RAG BGM 매칭 → LLM 자막 대본 → 검증 (부적절 표현 필터) → FFmpeg 렌더 → S3 업로드

내가 한 일

  • LangGraph 숏폼 생성 파이프라인 설계 · 구현 (에이전트 5단계)
  • Celery 비동기 영상 생성, 상태 폴링 · 재생 API, presigned URL 썸네일
  • mood_tag 기반 BGM 매칭과 폴백 전략, Gemini 할당량 초과 시 OpenAI 폴백
  • 배지 도메인 (모델 · 서비스 · 라우터, 카테고리 기반 자동 지급)
  • 마이 페이지 (React Native): 퀘스트 타임라인, 칭호 · 아이템, 프로필 수정

AI 실시간 통역 & 회의 어시스턴트

실시간으로 듣고 번역하고, 회의가 끝나면 누가 무슨 말을 했는지 나눠 요약해 주는 웹 앱.

기간 2025.10 ~ 2025.12인원 3명담당 초기 구조 · 실시간 음성 스트리밍

Faster-Whisper 로 듣고 Google 번역으로 옮기며, 회의 뒤에는 WhisperX · Pyannote 로 화자를 나누고 KoBART 로 요약합니다. VRAM 2~4GB GPU 나 CPU 에서도 돌아가게 만들었습니다.

마이크 → Silero VAD → Faster-Whisper STT → 번역 → Socket.IO 화면 출력 → (회의 뒤) 화자 분리 → KoBART 요약

내가 한 일

  • 첫 동작 버전 작성: Flask 서버 · Faster-Whisper 받아쓰기 · Google 번역 · SQLite 저장 · KoBART 요약 · 웹 화면 (+530줄)
  • webrtcvad 로 말소리만 잘라 받아쓰기, Flask-SocketIO 로 자막을 화면에 실시간 전송
  • 스트리밍 번역: 노이즈 제거, 문장 끝 판단, 중간 번역 결과 먼저 보내기
  • 번역 결과를 Edge-TTS 로 읽어 주기, VB-CABLE 로 영상 소리를 입력으로 잡기
  • 번역 방향 고르기 (한국어 ↔ 영어 등) 화면 · 서버 연동
